# Portfolio Frontend

This repository contains the public personal portfolio website built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**.

## Features
- Responsive, modern UI
- Projects showcase with media from Cloudflare R2 and Cloudinary
- Blog rendered from MDX
- SEO-optimized with proper meta tags

## Development
`ash
npm install
npm run dev
`

Deploys automatically to Vercel on pushes to main.
